# Playlist Maker

Учебное Android-приложение для поиска музыки, создания плейлистов и сохранения
избранных треков, разрабатываемое по курсу Яндекс Практикума.

Сейчас реализованы главный экран и переходы на заготовки экранов поиска
и настроек. Кнопки плейлистов и избранного пока показывают уведомления о нажатии.

Приложение написано на Kotlin с интерфейсом на Jetpack Compose и Material 3.
Для сборки используется Gradle Kotlin DSL. Минимальная поддерживаемая версия —
Android 10 (API 29).

Код организован с учётом принципов SOLID: интерфейс получает обработчики действий
через параметры, а Activity отвечают за переходы между экранами и системные действия.
Инструментальные тесты проверяют открытие поиска и настроек, а также возврат
в главное меню.
